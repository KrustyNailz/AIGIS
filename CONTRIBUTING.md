# Contributing to AIGIS

AIGIS is an open-source protocol donated to the AI industry. Contributions are welcome.

## How to Contribute

1. **Fork** this repository
2. Create a **feature branch** (`git checkout -b feature/your-feature`)
3. **Commit** your changes
4. **Push** to your branch
5. Open a **Pull Request**

## What We're Looking For

- Reference implementations in any language
- Registry service implementations
- Integration guides for specific AI platforms
- Security audits and vulnerability reports
- Documentation improvements
- Translation to other languages

## Guidelines

- Keep the protocol specification changes minimal and backwards-compatible
- Reference implementations should include tests
- Security issues should be reported privately to partners@kymatech.io before public disclosure

## Code of Conduct

Be respectful. Be constructive. Focus on making AI safer for everyone.
